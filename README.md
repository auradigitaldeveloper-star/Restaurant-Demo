# AURA — Modern Cinematic Gastronomy & Fine Dining

A **luxury, cinematic restaurant website demo** built using **React 19**, **Tailwind CSS**, and **Framer Motion**. Designed for world-class dining establishments, Michelin-starred culinary sanctuaries, and high-end hospitality brands.

---

## ✨ Features & Design Highlights

- **Full Glassmorphism UI System**: Multi-layered backdrop blurs (`backdrop-filter: blur(20px)`), subtle gold specular borders, and soft atmospheric shadows.
- **Cinematic Dark Palette**: Curated dark luxury tones (`#080808`, `#111111`, `#171717`) with warm champagne & gold accents (`#d4af37`, `#f3e5ab`).
- **Editorial Typography**: Pairing *Cormorant Garamond* serif headings with modern *Outfit* and *Plus Jakarta Sans* body text.
- **Micro-Animations & Smooth Motion**:
  - Full-viewport cinematic hero with subtle slow zoom-out and staggered line-by-line typography reveals.
  - Custom minimalist luxury cursor with dynamic spring physics and contextual badges (`VIEW`, `DETAILS`, `RESERVE`).
  - Interactive Web Audio API generative warm ambient soundscape generator.
  - Table-side confetti celebrations on reservation confirmation.
- **Complete Page & Section Architecture**:
  1. **Home**: Hero, Floating Reservation Bar, Story Teaser, Signature Dish Showcase, Tasting Menu Preview, Curated Experiences, Chef Profile, Critical Acclaim Testimonials.
  2. **Menu**: Digital menu collection with search, dietary filters (`GF`, `DF`, `VG`, `NF`), category tabs, and 12-Course Degustation showcase.
  3. **Menu Item Details (Modal)**: High-resolution culinary profile, ingredients breakdown, allergen notices, and Head Sommelier wine pairings.
  4. **Our Story**: 5 narrative chapters (The Genesis, The Philosophy, The Provenance, The Architecture, The Horizon), zero-waste laboratory, and culinary brigade profiles.
  5. **Experiences**: The Chef's Immersion Table, Grand Sommelier Cellar, Romantic Starlit Conservatory, and Private Dining Salon *Le Sanctuaire*.
  6. **Gallery**: Masonry/editorial photography grid with category filtering and keyboard-navigated fullscreen Lightbox.
  7. **Table Reservations**: Multi-step booking engine with atmosphere/table type selection, calendar date, time slots, guest counter, and instant confirmation dossier.
  8. **Contact & Concierge**: Dark glass inquiry form, Mayfair location specs, operating hours, and valet arrival instructions.

---

## 🛠️ Technology Stack

- **Framework**: React 19 (`react` & `react-dom`)
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Custom Glass Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Audio Synthesis**: Web Audio API (No external audio file dependencies)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/auradigitaldeveloper-star/Restaurant-Demo.git
cd Restaurant-Demo
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
